# speckle_RNA_dynamics_paper

Code accompanying the manuscript [Formation of an RNA-mediated nuclear compartment](https://www.biorxiv.org/content/10.64898/2026.08.20.746005v1?ct=)

The repository is organized into three directories: **Figures**, **LCHiC** and 
**FA_traces**. The **Figures** directory contains several sub-directories for which 
each top-level directory reproduces the panels of one main figure (and its associated 
Extended Data figure).  The **LCHiC** directory provides instructions and test data to 
derive Loss Of Structure (LOS) measurements generated from Liquid 
Chromatin Hi-C (LC-HiC) data and LOS residual measurements generated from the 
integration of LC-HiC and DpnII-seq datasets. The **FA_traces** directory provides 
instructions and test data to calibrate, normalize and plot raw Agilent Fragment Analyzer 
data in a similar manner to that done using Agilent PROsize software.
